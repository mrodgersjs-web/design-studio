# Workflow: design

<required_reading>
1. `../references/criteria.md`
2. `../references/release-rule.md`
</required_reading>

<process>
## Step 1: Brief
Write audience, viewing context, goal, constraints, success condition, named emotional target, and the exact misunderstanding the design must eliminate. Stop if GATE 11 cannot score 2.

## Step 2: Communication problem
Answer the six proof questions in SKILL.md. Name the single next action. Name the competing element to remove.

## Step 3: Hierarchy
Decide first fixation, second/third order, and reading path using only size, weight, color, and spacing. Do not add effects until GATE 21 and GATE 31 can score 2.

## Step 4: Constrained composition
Build the artifact. Every major visual choice gets one ledger line: decision → comprehension, desire, trust, or action. No decoration without a function.

## Step 5: Implementation
Clear the coding-agent gates in `criteria.md`. Semantic HTML, keyboard, focus, reduced-motion, tokens, states, touch targets, no hierarchy-breaking layout shift.

## Step 6: Handoff
Emit: rendered artifact, scorecard JSON in the `templates/scorecard.json` shape, decision ledger, responsive screenshots, accessibility notes, unresolved risks. Then run `workflows/critique.md`. Do not self-approve.
</process>

<success_criteria>
- [ ] Communication problem is named
- [ ] Decision ledger exists
- [ ] Scorecard JSON exists
- [ ] Critique workflow has not been skipped
</success_criteria>
